One funny line, at most 200 characters, that lands on a cold read: my therapist told me to talk to my inner child, so I did, and now we're both grounded.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 86 characters) to the output directory. It uses only the Python 3 standard library, needs no network, and two runs produce byte-identical files.
